## What round 1 showed

Surviving mutants that pointed at real gaps in the tests (the code was right, nothing
checked it):

- **Dedupe could delete a different file without a test failing.** Replacing the content
  digest by a constant, or answering "identical" when a file cannot be examined, survived:
  no test compared two same-sized files with different bytes. A bug there deletes a file that
  is not a duplicate. Now pinned by `test_files_of_the_same_size_but_different_bytes_are_not_identical`,
  `test_dedupe_keeps_a_same_named_file_with_other_bytes`, `test_a_file_that_cannot_be_examined_is_not_identical`.
- **A symlink could be turned into a hard link to its target** (`is_file() and not is_symlink()`
  weakened to `or`): `test_a_symlink_is_moved_as_a_symlink`.
- **Undo**: stopping at the first failed entry instead of continuing, not counting or not
  settling vanished files, not recreating a removed source folder, not reporting the run id.
- **Journal**: settlement verdicts, version 1 sequence numbers and ops, a versioned line that
  carries `moves` being read as version 1, the compaction boundary.
- Skip reasons were only checked as substrings, so a mangled reason passed.

The property tests written in the same change also found a real defect in the code: a file
name containing U+2028, U+2029 or U+0085 lost its journal entry (see `CHANGELOG.md`).

## The 15 survivors, reviewed as equivalent

| Mutant | Why it is equivalent |
|---|---|
| `Journal._append` 6, 8, 11 (`ensure_ascii` changed) | escaped and raw JSON decode to the same record; lines are split on `\n` only, which JSON always escapes |
| `_v1_run_id` 7 (`"UTF-8"` for `"utf-8"`) | same codec |
| `_run_of` 4, 8, 9, 17 | only decides which lines compaction keeps; every changed case is a line `runs()` already ignores (no `v`, or a non-string run), so the kept runs are identical |
| `build_ref` 6, `not_yet_reason` 5 (`lstrip("XX.XX")`) | the suffix is lower-cased first, so an upper-case `X` never occurs |
| `build_ref` 20 (always calls the extractor) | `extract_text` returns `""` for anything that is not a file |
| `build_ref` 26 (drops `max_bytes`) | `extract_text` has the same default, 4000 |
| `_digest` 10, 11 (chunk size) | reading in one block or in 65 537-byte blocks gives the same digest |
| `files_identical` 3 (`and` to `or` on `is_file`) | a non-file has no digest (`None`), so the comparison still answers "not identical" |

Timeouts (4) are mutants that make `unique_destination` or `_digest` loop forever; the test
run is stopped, which counts as detected.
